# راهنمای فارسی OmniRoute

## معرفی

OmniRoute یک AI Gateway متن‌باز است که امکان اتصال و مدیریت چندین مدل و سرویس هوش مصنوعی را از طریق یک رابط یکپارچه فراهم می‌کند.

## نصب با Docker
