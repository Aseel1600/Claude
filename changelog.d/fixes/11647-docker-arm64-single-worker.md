- **fix(docker):** drop the `linux/arm64` Docker publish build to 1 Next.js page-data worker (`OMNIROUTE_BUILD_WORKERS` `3 → 2`) ([#11647](https://github.com/diegosouzapw/OmniRoute/pull/11647)). The 2026-08-25 fix (7 → 2 workers, #10060) modeled 2 workers as fitting the 16 GB `ubuntu-24.04-arm` runner's budget, but 60+ consecutive `Build Docker (linux/arm64)` runs since 2026-08-24 still died with `ResourceExhausted: ... cannot allocate memory` right after `Collecting page data using 2 workers` — the `WORKER_PEAK_MB=2560` inference in `tests/unit/docker-build-memory-budget.test.ts` undercounted the real per-worker RSS. Raises `WORKER_PEAK_MB` to 4096 so the regression test now correctly rejects the 2-worker config it previously passed by mistake; new worst case is `6144 + 1×4096 = 10240 MB`, ~2 GB under the 12288 MB budget.
