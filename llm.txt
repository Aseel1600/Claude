1|# OmniRoute
2|
3|> OmniRoute is a free, open-source AI Gateway that acts as a universal API proxy for multi-provider LLMs. It provides smart routing, automatic fallback, load balancing, and format translation across 349 AI providers — all through a single OpenAI-compatible endpoint. Includes a built-in MCP Server (110 tools), A2A v0.3 protocol, Memory/Skills systems, Cloud Agents (codex, cursor, devin, jules), Guardrails framework, and an Electron desktop app.
4|
5|## Overview
6|
7|OmniRoute solves the problem of managing multiple AI provider subscriptions, quotas, and rate limits. It sits between your AI-powered tools (IDE agents, CLI tools) and AI providers, routing requests intelligently through a 4-tier fallback system: Subscription → API Key → Cheap → Free.
8|
9|**Key value:** One endpoint (`http://localhost:20128/v1`), unlimited models, zero downtime, minimal cost.
10|
11|**Current version:** 3.8.50
12|
13|## Tech Stack
14|
15|- **Runtime:** Node.js `>=22.0.0 <23 || >=24.0.0 <27`, ES Modules (`"type": "module"`)
16|- **Framework:** Next.js 16 (App Router) with TypeScript 6
17|- **Database:** SQLite via better-sqlite3 (local, zero-config, 159 migrations)
18|- **State management:** Zustand (client), SQLite (server persistence)
19|- **UI:** React 19, Tailwind CSS 4, Recharts for analytics, @lobehub/icons for 130+ provider SVG icons
20|- **Auth:** OAuth 2.0 (PKCE) for providers, bcrypt for local user auth
21|- **Schemas:** Zod v4 for all API / MCP input validation
22|- **Background jobs:** Custom token health check scheduler, 24h model auto-sync
23|- **Streaming:** Server-Sent Events (SSE) for real-time proxy responses
24|- **Proxy engine:** Custom pipeline with format translation, circuit breaker, rate limiting, auto-combo engine
25|- **i18n:** next-intl with 43 languages
26|- **Desktop:** Electron (cross-platform: Windows, macOS, Linux)
27|- **Package:** Published on npm (`omniroute`) and Docker Hub (`diegosouzapw/omniroute`)
